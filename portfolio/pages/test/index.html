云端日记本 App

把你的小情绪，变成天空中最柔软的云朵。一个专注于治愈和情绪记录的轻量级 Web 应用。

项目界面截图 / 演示 GIF

🔭 诞生的故事

在快节奏的现代生活中，我们经常会感到焦虑和疲惫。我开发这款“云端日记本”的初衷，是希望能在互联网的某个角落，为大家提供一个绝对安全、柔软且治愈的树洞。在这里，你不需要排版，不需要完美的文笔，只需记录下当下的情绪碎片。

🎯 核心魔法（功能亮点）

  • 情绪天气系统： 用户在记录日记时可以选择当前的情绪，系统会自动将情绪映射为不同颜色和形状的“云朵”。
  • 沉浸式白噪音： 内置了雨声、篝火、森林等多种高质量白噪音，开启日记本的瞬间即刻放松。
  • 时光信箱： 支持写一封“给未来自己的信”，它将在你设定的那一天像流星一样降落在你的屏幕上。
  • 隐私至上： 所有的日记数据默认在本地浏览器加密存储，也可以选择同步到个人的云端。
💡 设计思考： 为了营造极致的治愈感，我在 UI 上彻底摒弃了直角和纯黑色。所有的按钮都像果冻一样柔软，阴影使用了带有扩散的大范围有色弥散阴影，仿佛页面在微微发光。

🛠️ 打造飞船的工具（技术栈）
